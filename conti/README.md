# Divisore conti

App web (PWA) per dividere lo scontrino tra amici. Funziona offline e si installa sulla Home dell'iPhone.
Ora vive nel repository `le-mie-app`, alla cartella `conti/`: https://sizzomane.github.io/le-mie-app/conti/

## Cosa fa
- Conti multipli salvati sul telefono (nessun server, nessun account)
- Nomi salvati in rubrica
- Foto dello scontrino: legge le voci sul telefono (OCR italiano incluso, circa 9 MB), poi le controlli e correggi
- Quote condivise, chip "Tutti", voci divise tra tutti
- Condividi riepilogo con il foglio di condivisione dell'iPhone

## Aggiornare l'app
Dopo ogni modifica cambia `VERSION` in `sw.js` (es. `conti-v3`).
